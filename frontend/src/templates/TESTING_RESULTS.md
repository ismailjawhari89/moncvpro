## 🐛 Known Issues & Limitations
1. **ATS Text Extraction**: The current PDF engine generates an image-based PDF (via canvas). This is standard for complex visual layouts but suboptimal for ATS parsing.
   - *Mitigation*: The `ATS` export mode should ideally switch to a server-side text-based PDF generation or client-side raw text export in the future.
2. **Page Breaks**: Automatic page breaking inside a text block (like a long description splitting heavily) can visual cut text in `html2canvas`.
   - *Workaround*: Users should manually adjust spacing or we implement a "smart page break" detector component.
